Relayfile turns connected work tools into a shared file tree. Agents can read what changed, react to events and send edits back through familiar file operations.

## Get started

Start with the [Agent Relay getting-started guide](https://agentrelay.com/docs/getting-started). See the [repository guide](docs/repository-guide.md) for hosted integrations, local mounts, SDKs and development.
